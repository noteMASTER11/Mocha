# Mocha — мультифакторный симулятор траектории струи 🚽🪐

**Mocha** — это веб-симулятор, который моделирует полёт струи (и тяжёлых частиц в ней) в разных условиях:
гравитация планет, ветер, расстояние до унитаза, разброс, тяжёлые примеси и даже генерация пацанского отчёта
через Gemini на основе формального.

Проект создан для фанатично детального, но ироничного анализа того,
сколько процентов «материала» реально долетает до унитаза.

---

## Основные возможности

1. **Моделирование траектории струи**:
   - начальная скорость (v0);
   - угол вылета;
   - коэффициент сопротивления;
   - плотность жидкости.

2. **Гравитация разных тел Солнечной системы**:
   - Меркурий, Венера, Земля, Луна, Марс;
   - Юпитер, Сатурн, Уран, Нептун (как газовые гиганты — расчёт с гипотетической платформы);
   - Плутон.
   - Учитывается изменение ускорения свободного падения с высотой:
     g(y) = g0 * (R / (R + y))^2

3. **Тяжёлые частицы в струе**:
   - выбор материала: уран, плутоний, сталь, золото, сурьма;
   - количество частиц от 0 до 10 000;
   - траектории частиц рисуются отдельно (с учётом большей плотности и дисперсии).

4. **Геометрия унитаза**:
   - расстояние от источника до кромки унитаза;
   - высота кромки относительно уровня члена.

5. **Ветер**:
   - направление (0–359°);
   - скорость ветра (м/с);
   - учитывается влияние на траекторию.

6. **Вероятность попадания**:
   - моделирование Монте-Карло;
   - вычисление процента попадания и промаха.

7. **Текстовый отчёт**:
   - формальный и пацанский стиль;
   - опциональная генерация через Gemini.

8. **Интеграция с Gemini**:
   - генерация пацанского отчёта через Google Gemini API.

## Установка и запуск

```bash
git clone https://github.com/<your-username>/mocha.git
cd mocha
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Открой в браузере: http://127.0.0.1:5001

---

## Настройка Gemini API

Создай API ключ на [Google AI Studio](https://aistudio.google.com/api-keys).

Варианты использования:

### Через переменную окружения

```bash
export GEMINI_API_KEY="ВАШ_КЛЮЧ"
```

### Или жёстко в коде (только для локалки)

```python
from google import genai
gemini_client = genai.Client(api_key="ВАШ_КЛЮЧ")
```
